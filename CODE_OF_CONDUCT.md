# Code of Conduct

Tetrix is committed to a welcoming, respectful, and harassment-free community.
Participants are expected to communicate constructively, accept good-faith
feedback, and focus on the work rather than on people.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, deliberate disruption, and publishing private information without
permission.

Project maintainers may remove comments, close issues, or restrict
participation when behavior violates these expectations. Report conduct issues
privately through the repository's GitHub contact or security reporting channel.
