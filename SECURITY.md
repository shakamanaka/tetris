# Security policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature or contact the
repository maintainers privately. Do not publish exploit details in a public
issue until a fix or mitigation is available.

Include the affected version, operating system, reproduction steps, and any
relevant logs. The application is designed to work offline and does not send
game scores or settings to a server.
